# Virtual Guitar - React + Vite Migration

## 🎸 Giới thiệu
**Virtual Guitar** là một ứng dụng mô phỏng chơi đàn guitar trực tuyến. Dự án đã hoàn tất quá trình chuyển đổi quan trọng từ JavaScript thuần (Vanilla JS) sang **React**, sử dụng công cụ xây dựng **Vite** để tối ưu hóa hiệu suất và trải nghiệm phát triển [1], [2].

## 🚀 Các cập nhật mới nhất
Dựa trên lịch sử phát triển gần đây, dự án đã được nâng cấp đáng kể về cả giao diện lẫn tính năng [1]:
- **Di cư sang React:** Toàn bộ logic được cấu trúc lại theo component để dễ dàng mở rộng [1].
- **Cải thiện Gameplay:**
    - **Hệ thống tính điểm (Score Tracking):** Theo dõi thành tích người chơi [1].
    - **Phản hồi thời gian thực (Feedback):** Hiển thị phản hồi ngay khi tương tác [1].
    - **Hệ thống hợp âm (Chords):** Tối ưu hóa cách xử lý và hiển thị các hợp âm guitar [1].
- **UI Redesign:** Giao diện người dùng được thiết kế lại hiện đại và trực quan hơn [1].

## 🛠 Công nghệ sử dụng
- **Framework:** React [1].
- **Build Tool:** Vite (cung cấp HMR và hỗ trợ ESLint) [2].
- **Ngôn ngữ:** JavaScript (chiếm 92.8% mã nguồn) [3].
- **Styling:** CSS và HTML [3].

## 📂 Cấu trúc thư mục chính
- `virtual-guitar/src`: Chứa các component và logic chính của ứng dụng React [4].
- `virtual-guitar/public`: Các tài nguyên tĩnh như hình ảnh, âm thanh [4].
- `vite.config.js`: Tệp cấu hình cho công cụ Vite [4].
